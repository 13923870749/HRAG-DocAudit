\section{Self-RAG and ReAct baselines on C3PA}
\label{app:tier2_transfer}

Self-RAG \cite{asai2023selfrag} and ReAct \cite{yao2023react} are evaluated on the public C3PA test split ($n{=}456$) under the Tier-1 proxy. CNAS Tier-2 deployment was limited to single-pass Rule, RAG, Ensemble, and \HRAG{} configurations; multi-step Self-RAG and ReAct loops were outside the partner-laboratory API quota for proprietary test-report data. Both baselines therefore share the same hybrid-retrieval backbone as RAG-Only ($\lambda{=}0.6$, top-$M{=}5$, document-scoped chunks, BM25 $k_1{=}1.5$, $b{=}0.75$) and the same evidence-threshold classifier, differing only in inference policy.

\subsection{Implementation}
\label{app:tier2_impl}
\begin{itemize}
  \item \textbf{Self-RAG}: reflection threshold $=0.8$ (Asai et al., mapped to hybrid retrieval scores); $\mathrm{max\_retrieval}{=}5$; unsupported outputs map to predicted non-compliance to preserve binary labels.
  \item \textbf{ReAct}: $\mathrm{max\_steps}{=}3$; each step invokes the same hybrid retriever; the final action returns a binary compliance decision.
\end{itemize}

\subsection{Cross-domain interpretation}
\label{app:tier2_caution}

C3PA (English privacy policies, CCPA mandates) and CNAS (Chinese test reports, accreditation criteria) differ in language, genre, and checklist structure, so baseline ordering on C3PA should not be read as a CNAS forecast. On C3PA, ReAct exceeds RAG-Only while Self-RAG trails slightly (51.8\% vs.\ 52.4\%). Self-RAG's reflection step reverses about 6\% of initial positives; qualitative review of 50 cases shows that many reversals occur when mandate wording diverges lexically from the retrieved clause (e.g., ``sell/share'' vs.\ ``transfer''), converting label-consistent positives into predicted non-compliance. Fixed reflection thresholds thus appear sensitive to adversarial paraphrase in privacy-policy text---a phenomenon that may not carry over to CNAS technical prose and that motivates domain-specific calibration before deployment.
