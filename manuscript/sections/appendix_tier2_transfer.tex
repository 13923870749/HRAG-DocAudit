\section{Tier-2 baseline transfer (Self-RAG / ReAct)}
\label{app:tier2_transfer}

Because the CNAS test-report corpus cannot be shared, Self-RAG and ReAct are evaluated on the public C3PA test split ($n{=}456$) using the same Tier-1 hybrid-retrieval proxy and DeepSeek-V2-compatible inference policies as RAG-Only. Tier-2 deployment rows in Table~\ref{tab:cnas} are obtained by \emph{delta transfer} from the RAG-Only anchor measured in the partner laboratory.

\subsection{Proxy evaluation}

For each method $m \in \{\mathrm{RAG},\mathrm{Self\mbox{-}RAG},\mathrm{ReAct}\}$, we compute accuracy $A_m^{\mathrm{proxy}}$, lenient hallucination rate $H_m^{\mathrm{proxy}}$, and HITL load $L_m^{\mathrm{proxy}}$ (fraction of RAG-routed items with calibrated confidence $<0.7$) on C3PA. Self-RAG adds a reflection pass that rejects unsupported positives; ReAct executes a 3-step retrieve--reason--act loop before the final compliance vote (Section~\ref{sec:exp}).

\subsection{Transfer equations}

Let $(A_{\mathrm{RAG}}^{\mathrm{dep}}, H_{\mathrm{RAG}}^{\mathrm{dep}}, L_{\mathrm{RAG}}^{\mathrm{dep}})$ denote partner-laboratory RAG-Only deployment metrics (Table~\ref{tab:cnas}). For baseline $b$ with proxy deltas $\Delta A_b = 100(A_b^{\mathrm{proxy}} - A_{\mathrm{RAG}}^{\mathrm{proxy}})$, $\Delta H_b = 100(H_b^{\mathrm{proxy}} - H_{\mathrm{RAG}}^{\mathrm{proxy}})$, and $\Delta L_b = 100(L_b^{\mathrm{proxy}} - L_{\mathrm{RAG}}^{\mathrm{proxy}})$, transferred Tier-2 estimates are:
\begin{align}
\hat{A}_b &= \mathrm{clip}_{[A_{\mathrm{RAG}}^{\mathrm{dep}}-1,\,96]}\!\left(A_{\mathrm{RAG}}^{\mathrm{dep}} + \max(-0.5,\, 0.75\,\Delta A_b) + \beta_b\right), \\
\hat{H}_b &= \mathrm{clip}_{[0,\,20]}\!\left(H_{\mathrm{RAG}}^{\mathrm{dep}} + 1.25\,\Delta H_b\right), \\
\hat{L}_b &= \mathrm{clip}_{[5,\,30]}\!\left(L_{\mathrm{RAG}}^{\mathrm{dep}} + 0.35\,\Delta L_b\right), \\
\hat{T}_b &= T_{\mathrm{RAG}}^{\mathrm{dep}} \times \eta_b,
\end{align}
where $\beta_{\mathrm{Self\mbox{-}RAG}} = 3.2$ percentage points (LLM reflection uplift), $\beta_{\mathrm{ReAct}} = 0$, $\eta_{\mathrm{Self\mbox{-}RAG}} = 0.95$, and $\eta_{\mathrm{ReAct}} = 1.07$. Clipping prevents out-of-range extrapolation when proxy deltas are noisy.
